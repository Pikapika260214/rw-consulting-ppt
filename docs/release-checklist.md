# Release Checklist

Use this checklist before publishing or refreshing the public repository.

## Editorial Baseline

- Keep `docs/english-publication-style-guide.md` as the English-first editorial QA baseline.
- Run a Chinese-residue scan across Markdown, YAML, and Python help text.
- Allow only intentional Chinese content, such as the WeChat community entry and the attribution note.

## Showcase Assets

- Verify the README renders the hero image, workflow diagram, one Chinese reference example, one English localized example, and the WeChat QR code.
- Confirm the Chinese AI glasses source deck is not shown as a public showcase example.
- Keep example preview paths relative to the repository root.

## Capability Claims

- Keep the `rw-consulting-ppt` default output described as PNG first and image-only PPTX.
- Keep `ppt-to-editable` framed as limited post-confirmation editability recovery, not a full-native deck generator.
